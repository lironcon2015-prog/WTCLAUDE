# 🎯 דארטס — לוח ניקוד

אפליקציית ניקוד למשחק דארטס X01 ל-1–4 שחקנים. מקישים על מקום הפגיעה במטרה,
והמערכת אוכפת את חוקי המשחק: אאוט (bust), חובת סיום בדאבל, סיבוב תורים וניהול legs.

## הרצה

אין שלב בנייה ואין תלויות. פותחים את `index.html` בדפדפן — בלחיצה כפולה על הקובץ
(`file://`) או דרך כל שרת סטטי. הקבצים יושבים בשורש הריפו, ולכן GitHub Pages
מגיש אותם כמו שהם.

## התקנה כאפליקציה

האפליקציה היא PWA וניתן להתקין אותה במסך הבית:

- **אנדרואיד (Chrome)** — יופיע כפתור "התקן את האפליקציה" במסך ההגדרה, או דרך תפריט ⋮ ← *התקן אפליקציה*. נפתחת במסך מלא, נעולה לאנכי.
- **iOS (Safari)** — שיתוף ← *הוסף למסך הבית*. אין ל-iOS התקנה תכנותית, ולכן הכפתור לא מוצג שם. iOS מתעלם מ-`display` ומ-`orientation` ופותח בחלון עצמאי בלי נעילת כיוון.

אחרי ההתקנה האפליקציה **עובדת לגמרי בלי אינטרנט** — service worker שומר את כל קליפת האפליקציה, והמצב ממילא נשמר ב-localStorage.

## מה יש

- **מטרה מלאה ב-SVG** ברדיוסים של תקן WDF, עם שכבת פגיעה מורחבת ובלתי-נראית
  שמגדילה פי 2.25 את טבעות הדאבל והטריפל — כדי שאפשר יהיה לפגוע בהן באצבע.
- **חוקי X01 מלאים**: כניסה חופשית, חובת סיום בדאבל, ושלושת מקרי האאוט
  (חריגה מתחת לאפס, נותר 1, ואפס שהושג בלי דאבל). הבול ממודל כ-25×2, ולכן
  הוא סוגר משחק בלי שום מקרה מיוחד בקוד.
- **Legs** במבנה best-of-X, עם החלפת שחקן פותח בכל leg.
- **הצעות סגירה** לכל ניקוד שניתן לסגור, כולל התאמה למספר החצים שנותרו בתור.
- **ביטול** של חץ אחד בכל לחיצה, כולל אחורה מעל אאוט, מעל גבול תור ומעל מעבר ליג.
- **שמירה אוטומטית** — סגירת הדפדפן באמצע משחק לא מאבדת כלום, וגם ההיסטוריה
  לביטול שורדת.
- **מקלדת גיבוי** למי שמעדיף להזין מספרים במקום להקיש על המטרה.

## מבנה

| קובץ | תפקיד |
|---|---|
| `board.js` | גאומטריית המטרה, רינדור ה-SVG וזיהוי הפגיעות |
| `engine.js` | מעברי המצב של המשחק — פונקציות טהורות, אפס DOM |
| `checkout.js` | חיפוש מסלולי סגירה, מחושב מראש לשלוש טבלאות |
| `storage.js` | התמדה ב-localStorage |
| `app.js` | הבקר: מחזיק את המצב וההיסטוריה, מחבר הכול ומרנדר |
| `tests.js` | בדיקות עצמיות |
| `manifest.webmanifest` | הגדרות ההתקנה. `start_url` ו-`scope` יחסיים (`"."`) כדי שהכול יעבוד גם בתת-נתיב של GitHub Pages, גם בשורש דומיין וגם בפורק |
| `sw.js` | service worker — precache לעבודה בלי רשת |
| `tools/make-icons.js` | מייצר את האייקונים מהגאומטריה של `board.js`. כלי פיתוח, לא נטען בזמן ריצה |

### טקס שחרור — שני מספרי גרסה

בכל שינוי בקבצים צריך להעלות **שניהם** ביחד:

1. `?v=N` שב-`index.html` — מנטרל את מטמון ה-HTTP של הדפדפן.
2. `CACHE_VERSION` שב-`sw.js` — מנטרל את מטמון ה-service worker. ורשימת `ASSETS` שם חייבת לשאת את אותן מחרוזות `?v=N` בדיוק, כי מחרוזת השאילתה היא חלק ממפתח המטמון.

ליצירת האייקונים מחדש: `node tools/make-icons.js`

## בדיקות

מוסיפים `?test=1` ל-URL ופותחים את הקונסולה:

```
index.html?test=1
```

162 טענות שמכסות את טבעת המספרים, את הסכמת `scoreAt` עם הגאומטריה המצוירת,
את מטריצת האאוט, את טבלת הסגירות (כולל הקבוצה הבלתי-אפשרית
159, 162, 163, 165, 166, 168, 169), ואת נאמנות הביטול.
